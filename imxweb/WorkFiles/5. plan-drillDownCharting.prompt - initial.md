# Plan: Drill-Down Charting Plugin (charts-plugin)

Build a new `charts-plugin` with a billboard.js chart sidesheet using **in-place drill-down** (Localities → Departments via `chart.load()` + breadcrumb), opening a **nested persons table sidesheet** only at Level 3. Custom aggregation API for performance. Gated by `Custom\Charts` role. Registered as a Dashboard-SmallTiles badge tile.

---

## Architecture

```
Dashboard SmallTile (badge: locality count)
  └─ click → ChartsDrilldownSidesheetComponent (single sidesheet)
       ├─ State: 'localities' → Pie/Bar switchable (persons per locality)
       │     └─ click slice/bar → transitions to 'departments'
       ├─ State: 'departments' → Bar chart (persons per dept in locality)
       │     └─ click bar → opens ChartsPersonsSidesheetComponent
       └─ Breadcrumb: [Localities] > [Selected Locality Name]

ChartsPersonsSidesheetComponent (nested sidesheet)
  └─ Mat table (locality+department filter)
       └─ row click → IdentitySidesheetComponent (existing)
```

## Key Design Decisions

- **In-place drill**: `chart.load()` for bar→bar transitions (smooth animation ~300ms). Pie↔bar toggle destroys/regenerates.
- **Custom API**: Server-side `GROUP BY` avoids fetching all persons client-side.
- **Back from Level 3**: Persons sidesheet closes → drill-down sidesheet remains at Level 2. No state lost.
- **Empty state**: Localities with no departments show "No Department" single bar or skip to table.
- **Separate plugin**: `charts-plugin` is independent from `geo-plugin` — different UX purpose (analytics vs. geographic).
- **SmallTiles**: Badge-style tile (compact, shows count) matching frozen-jobs-plugin pattern.

## Further Considerations

1. **Chart animations**: billboard.js supports transition duration on `chart.load()`. Recommend ~300ms for drill-down transitions.
2. **Empty states**: If a locality has no departments (persons assigned directly), Level 2 could show a single "No Department" bar or skip directly to Level 3.
3. **Back from Level 3**: When the persons sidesheet closes, the user returns to the Level 2 chart — no state reset needed since the drill-down sidesheet remains open behind it.
