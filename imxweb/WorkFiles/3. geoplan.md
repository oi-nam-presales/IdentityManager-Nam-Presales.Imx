# Plan: geo-plugin — Localities Map Dashboard Plugin

## TL;DR
A new Angular library plugin `geo-plugin` following the `frozen-jobs-plugin` / `utilities-plugin` blueprint. Adds a medium dashboard tile "Localities" (visible to users with AERole `Custom\Geo`). Tile click opens a Leaflet map sidesheet showing locality pins. Pin click opens a persons sidesheet (grid of ALL persons in that locality; only the current user's reports are clickable). Clicking a report row opens the standard `IdentitySidesheetComponent` from `qer`. No custom API `.tgz` needed — uses `QerApiService` directly.

---

## Decisions

- Map: **Leaflet + OpenStreetMap** (free, no API key) — `leaflet` + `@types/leaflet` added to workspace deps
- Auth: AERole `Custom\Geo`
- Persons grid: ALL persons in locality (admin scope); only user's reports are clickable
- Persons clickable check: load reports-in-locality via `PortalPersonReports.Get({ filter: [UID_Locality=uid], PageSize: -1 })` in parallel, store UIDs in a `Set<string>`
- Person identity sidesheet: use `IdentitySidesheetComponent` from `qer` (already exported in `qer/public_api.ts`)
- No custom API service — all data from standard `QerApiService` and `QerApiService.client` (V2Client from qer)

## Phase 4: GeoLocalitiesTileComponent

**`geo-localities-tile.component.ts`**
```typescript
import { Component, OnInit } from '@angular/core';
import { EuiSidesheetService } from '@elemental-ui/core';
import { EntityData } from '@imx-modules/imx-qbm-dbts';
import { imx_SessionService } from 'qbm';
import { QerApiService } from 'qer';
import { GeoMapSidesheetComponent } from '../geo-map-sidesheet/geo-map-sidesheet.component';

@Component({
  selector: 'imx-geo-localities-tile',
  templateUrl: './geo-localities-tile.component.html',
  standalone: false,
})
export class GeoLocalitiesTileComponent implements OnInit {
  public isAuthorized = false;
  public loading = true;
  public localities: EntityData[] = [];

  constructor(
    private readonly session: imx_SessionService,
    private readonly qerApiService: QerApiService,
    private readonly sidesheet: EuiSidesheetService,
  ) {}

  public async ngOnInit(): Promise<void> {
    try {
      const uidPerson = this.session.SessionState?.UserUid;
      if (uidPerson) {
        this.isAuthorized = await this.hasGeoRole(uidPerson);
      }
      if (this.isAuthorized) {
        const result = await this.qerApiService.client.portal_candidates_Locality_get({
          withProperties: '-PostalAddress,ZipCode,UID_DialogCountry,CustomProperty07,CustomProperty08,CustomProperty09',
          PageSize: -1,
        });
        this.localities = result.Entities ?? [];
      }
    } catch (error) {
      console.error('[GeoLocalitiesTile] Error during initialization:', error);
    } finally {
      this.loading = false;
    }
  }

  public onTileClick(): void {
    this.sidesheet.open(GeoMapSidesheetComponent, {
      title: 'Localities',
      padding: '0px',
      width: 'calc(100vw - 200px)',
      testId: 'geo-map-sidesheet',
      data: { localities: this.localities },
    });
  }

  private async hasGeoRole(uidPerson: string): Promise<boolean> {
    const pageSize = 100;
    let startIndex = 0;

    do {
      const result = await this.qerApiService.client.portal_person_rolememberships_AERole_get(uidPerson, {
        withProperties: '-RoleFullPath',
        PageSize: pageSize,
        StartIndex: startIndex,
      });

      const entities = result.Entities ?? [];

      if (entities.some((e) => e.Columns?.['RoleFullPath']?.Value === 'Custom\\Geo')) {
        return true;
      }

      startIndex += entities.length;
      if (entities.length === 0 || startIndex >= result.TotalCount) {
        break;
      }
    } while (true);

    return false;
  }
}
```

## Phase 5: GeoMapSidesheetComponent

**`geo-map-sidesheet.component.ts`**
```typescript
import { AfterViewInit, Component, ElementRef, Inject, OnDestroy, ViewChild } from '@angular/core';
import { EUI_SIDESHEET_DATA, EuiSidesheetService } from '@elemental-ui/core';
import { EntityData } from '@imx-modules/imx-qbm-dbts';
import * as L from 'leaflet';
import { GeoLocalityPersonsSidesheetComponent } from '../geo-locality-persons-sidesheet/geo-locality-persons-sidesheet.component';

@Component({
  selector: 'imx-geo-map-sidesheet',
  templateUrl: './geo-map-sidesheet.component.html',
  styleUrls: ['./geo-map-sidesheet.component.scss'],
  standalone: false,
  host: { 'data-component-id': 'geo-map-sidesheet' },
})
export class GeoMapSidesheetComponent implements AfterViewInit, OnDestroy {
  @ViewChild('mapContainer') mapContainer: ElementRef;

  private map: L.Map | null = null;

  constructor(
    @Inject(EUI_SIDESHEET_DATA) public data: { localities: EntityData[] },
    private readonly sidesheet: EuiSidesheetService,
  ) {}

  public ngAfterViewInit(): void {
    // Delay to allow EUI sidesheet open animation to settle before initializing Leaflet
    setTimeout(() => { this.initMap(); }, 150);
  }

  public ngOnDestroy(): void {
    this.map?.remove();
    this.map = null;
  }

  private initMap(): void {
    this.map = L.map(this.mapContainer.nativeElement).setView([20, 0], 2);

    L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
      attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors',
      maxZoom: 18,
    }).addTo(this.map);

    for (const locality of this.data.localities) {
      const lat = parseFloat(locality.Columns?.['CustomProperty07']?.Value ?? '');
      const lng = parseFloat(locality.Columns?.['CustomProperty08']?.Value ?? '');
      if (isNaN(lat) || isNaN(lng)) {
        continue; // skip localities without coordinates
      }

      const display  = locality.Columns?.['Display']?.Value ?? '';
      const address  = locality.Columns?.['PostalAddress']?.Value ?? '';
      const zip      = locality.Columns?.['ZipCode']?.Value ?? '';
      const country  = locality.Columns?.['UID_DialogCountry']?.Value ?? '';
      const tooltip  = [display, address, zip, country].filter(Boolean).join(', ');

      L.circleMarker([lat, lng] as L.LatLngTuple, {
        radius: 8,
        fillColor: '#0052cc',
        color: '#003d99',
        weight: 2,
        fillOpacity: 0.8,
      })
        .bindTooltip(tooltip, { permanent: false, direction: 'top', className: 'geo-map-tooltip' })
        .on('click', () => { this.onPinClick(locality); })
        .addTo(this.map!);
    }
  }

  private onPinClick(locality: EntityData): void {
    this.sidesheet.open(GeoLocalityPersonsSidesheetComponent, {
      title: locality.Columns?.['Display']?.Value ?? 'Locality',
      padding: '0px',
      width: '800px',
      testId: 'geo-locality-persons-sidesheet',
      data: {
        localityUid: locality.Keys?.[0] ?? '',
        localityName: locality.Columns?.['Display']?.Value ?? '',
      },
    });
  }
}
```

## Phase 6: GeoLocalityPersonsSidesheetComponent

**`geo-locality-persons-sidesheet.component.ts`**
```typescript
import { Component, Inject, OnInit } from '@angular/core';
import { EUI_SIDESHEET_DATA, EuiLoadingService, EuiSidesheetService } from '@elemental-ui/core';
import { PortalAdminPerson } from '@imx-modules/imx-api-qer';
import { CompareOperator, FilterData, FilterType } from '@imx-modules/imx-qbm-dbts';
import { calculateSidesheetWidth } from 'qbm';
import { IdentitySidesheetComponent, ProjectConfigurationService, QerApiService } from 'qer';

@Component({
  selector: 'imx-geo-locality-persons-sidesheet',
  templateUrl: './geo-locality-persons-sidesheet.component.html',
  styleUrls: ['./geo-locality-persons-sidesheet.component.scss'],
  standalone: false,
  host: { 'data-component-id': 'geo-locality-persons-sidesheet' },
})
export class GeoLocalityPersonsSidesheetComponent implements OnInit {
  public allPersons: PortalAdminPerson[] = [];
  public reportUidSet = new Set<string>();
  public loading = true;
  public displayedColumns = ['FirstName', 'LastName', 'CentralAccount'];

  private projectConfig: any;

  constructor(
    @Inject(EUI_SIDESHEET_DATA) public data: { localityUid: string; localityName: string },
    private readonly qerApiService: QerApiService,
    private readonly sidesheet: EuiSidesheetService,
    private readonly busyService: EuiLoadingService,
    private readonly configService: ProjectConfigurationService,
  ) {}

  public async ngOnInit(): Promise<void> {
    try {
      const filter: FilterData[] = [
        {
          Type: FilterType.Compare,
          Expression: {
            PropertyId: 'UID_Locality',
            Operator: CompareOperator.Equal,
            Value: this.data.localityUid,
          } as any,
        },
      ];

      const [adminResult, reportsResult] = await Promise.all([
        this.qerApiService.typedClient.PortalAdminPerson.Get({ filter, PageSize: -1 }),
        this.qerApiService.typedClient.PortalPersonReports.Get({ filter, PageSize: -1 }),
      ]);

      this.allPersons = adminResult.Data;
      this.reportUidSet = new Set(reportsResult.Data.map((p) => p.GetEntity().GetKeys()[0]));
    } catch (error) {
      console.error('[GeoLocalityPersonsSidesheet] Error loading persons:', error);
    } finally {
      this.loading = false;
    }
  }

  public isClickable(person: PortalAdminPerson): boolean {
    return this.reportUidSet.has(person.GetEntity().GetKeys()[0]);
  }

  public async onPersonRowClick(person: PortalAdminPerson): Promise<void> {
    if (!this.isClickable(person)) {
      return;
    }

    const uid = person.GetEntity().GetKeys()[0];
    const overlayRef = this.busyService.show();
    try {
      if (!this.projectConfig) {
        this.projectConfig = await this.configService.getConfig();
      }
      const personCollection = await this.qerApiService.typedClient.PortalPersonReportsInteractive.Get_byid(uid);
      const selectedIdentity = personCollection?.Data?.[0];
      if (!selectedIdentity) {
        return;
      }

      await this.sidesheet
        .open(IdentitySidesheetComponent, {
          title: 'Edit Identity',
          subTitle: selectedIdentity.GetEntity().GetDisplay(),
          padding: '0px',
          disableClose: true,
          width: calculateSidesheetWidth(1100, 0.7),
          icon: 'contactinfo',
          testId: 'geo-plugin-identity-sidesheet',
          data: {
            isAdmin: false,
            projectConfig: this.projectConfig,
            selectedIdentity,
            canEdit: false,
          },
        })
        .afterClosed()
        .toPromise();
    } catch (error) {
      console.error('[GeoLocalityPersonsSidesheet] Error opening identity sidesheet:', error);
    } finally {
      this.busyService.hide(overlayRef);
    }
  }
}
```

> **Fallback note**: If `PortalPersonReports.Get({ filter: [UID_Locality] })` returns an empty result due to the endpoint not supporting that filter, replace the reports query with:
> ```typescript
> const reportsResult = await this.qerApiService.typedClient.PortalPersonReports.Get({ PageSize: -1 });
> ```
> and filter client-side after loading all reports (acceptable when the user manages a bounded set).

### Runtime verification checklist

1. Login as user with `Custom\Geo` role → Localities tile visible on dashboard (icon-tile with "View Map" button)
2. Login without role → tile absent
3. Tile button click → map sidesheet opens at near-full width
4. Localities with lat/lng in `CustomProperty07`/`CustomProperty08` show as blue circle pins
5. Hover pin → tooltip shows locality display name + address + zip + country
6. Click pin → locality persons sidesheet opens; ALL persons in that locality listed
7. Non-report row → default cursor; click is ignored

## Pitfalls

| Problem | Cause | Fix |
|---|---|---|
| Leaflet map tiles not visible | `leaflet.css` not loaded | Add `node_modules/leaflet/dist/leaflet.css` to `angular.json` styles |
| Map renders as 0-height gray box | Container div has no height | Explicit `height: 600px` on `#mapContainer` is required |
| Map pins misaligned after sidesheet open | Leaflet initialized before EUI animation settled | `setTimeout(() => initMap(), 150)` in `ngAfterViewInit` |
| Map tiles broken when navigating back and forth | Leaflet map not destroyed on component teardown | `this.map?.remove()` in `ngOnDestroy()` |
| Leaflet tooltip styles not applying | Tooltip DOM is outside component's encapsulation boundary | Use `::ng-deep` in SCSS |
| `PortalPersonReports.Get()` filter by `UID_Locality` returns empty | Endpoint may not support that filter | Fallback: load ALL reports with `PageSize: -1`, filter client-side by locality uid |
| `IdentitySidesheetComponent` compile error in module | Mistakenly declared in `geo-plugin.module.ts` | Do NOT declare — it lives in `qer`; open via `EuiSidesheetService` |
| `calculateSidesheetWidth` not found | Wrong import source | `import { calculateSidesheetWidth } from 'qbm'` (not `qer`) |
| `FilterType` / `CompareOperator` not found | Wrong import source | `import { FilterType, CompareOperator } from '@imx-modules/imx-qbm-dbts'` |
| Map sidesheet too narrow for map | Default EUI sidesheet width | Set `width: 'calc(100vw - 200px)'` in `onTileClick()` |
| Plugin registers but tile doesn't appear | Double-loading via `loadThirdPartyModules` | Use `loadFirstPartyModules` ONLY (via `imx-plugin-config.json`) |
| Plugin chunk 404 in browser | Portal built before plugin library was built | Always run `nx build geo-plugin` before `nx run qer-app-portal:build:production` |
| "An unexpected server error occurred" dialog | API call throws without a `catch` block | All `async` calls must be wrapped in `try/catch` with `console.error` |
