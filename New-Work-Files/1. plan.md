# Plan: Create frozen-jobs-plugin Library

## TL;DR
Create a new Angular library `frozen-jobs-plugin` in the NX monorepo that registers a Dashboard-SmallTiles badge tile. The tile checks if the logged-in user belongs to the `QER_4_OperationsSupport` group, calls `GET /opsupport/queue/frozenjobs` to get a count, and opens a sidesheet with frozen job details on click.

## Phase 2: API Access Decision

The `opsupport_queue_frozenjobs_get` endpoint is under the opsupport API project. In the portal app context, the API client (`imx_SessionService.Client`) is a V2Client generated from the swagger — it should have the method available if the API server is configured to serve opsupport endpoints. If not, we'll need to use `AppConfigService.apiClient` directly with a raw HTTP call to `/opsupport/queue/frozenjobs`.

Fallback approach: Use `apiClient.processRequest()` for a direct HTTP GET.

## Phase 3: Security Group Check

Use `UserModelService.getGroups()` (calls `GET /portal/usergroups`) and check for group name `QER_4_OperationsSupport`. This is the same pattern used by `isAuditor()` in `qer-permissions-helper.ts`.

## Decisions

- Using `UserModelService.getGroups()` (portal API) for group check, not opsupport API
- Badge tile (Dashboard-SmallTiles) per user's choice
- No `ng-package.dynamic.json` — doc is outdated, current v10 doesn't use it
- No `tslint.json` — current v10 uses eslint (`.eslintrc.json`)
- No `enableIvy` in tsconfig.lib.prod.json — not needed in Angular 20
- No `compilationMode: partial` — not needed since this is a workspace library, not a published npm package
- Library named `frozen-jobs-plugin`, module named `FrozenJobsPluginModule`

## Further Considerations

1. **opsupport API availability**: If `opsupport_queue_frozenjobs_get()` is not available on the portal V2Client, we'll need a raw HTTP call via `apiClient`. We should test this first.
2. **Frozen jobs data schema**: The API returns `EntityCollectionData`. We'll need to extract column data for the sidesheet table (e.g., JobChainName, ErrorMessages, etc.).
